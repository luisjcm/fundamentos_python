# 🐍 Fundamentos de Python

Este repositorio contiene mi progreso, prácticas y laboratorios para dominar las bases y aplicaciones de Python. El código está estructurado en módulos progresivos para facilitar su lectura y ejecución.

## 📂 Estructura del Repositorio

*   **`modulo_1_introduccion/`**: Tipos de datos primitivos, manejo de variables, conversiones y formateo de cadenas (f-strings).
*   *(Próximamente)* **`modulo_2_control_flujo/`**: Lógica condicional, bucles `while` y `for`.
*   *(Próximamente)* **`modulo_3_estructuras_datos/`**: Listas, tuplas y diccionarios.
